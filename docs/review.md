# 代码审查与清理记录

审查日期：2026-10-22。范围：Rust core/db/FFI、Swift 共享层与平台服务、构建脚本、工程配置、迁移、文档和引用关系。结果来自静态审查、合同测试及跨平台编译，不代表完成真实模型、语音、签名和多设备发布验收。

## 修复

| 问题 | 修复与验证 |
|---|---|
| 云端订阅生成草稿时已创建，确认时重复创建；丢弃草稿仍留下订阅 | 订阅只在确认事务创建。增加确认、丢弃、自动保存与整批回滚测试 |
| 自动保存多笔账单逐笔提交，中途失败留下部分数据 | 复用通用草稿确认事务；第二笔插入失败时账单、订阅全部回滚，保留完整待确认草稿 |
| 资产合并同日快照触发唯一索引，操作不原子 | 同日复用目标快照 ID，兼容目标软删除行；校验 profile、币种和不同 ID，整个合并使用事务。增加冲突、软删除、回滚和拒绝无效合并测试 |
| CloudKit 忽略记录/操作失败、丢弃缺失 payload 的记录，仍可能推进游标 | 严格验证整页，应用成功并持久化游标后再取下一页；失败停止。覆盖 payload、类型、顺序与损坏游标合同 |
| CloudKit 本地水位确认失败仍当成功，状态可被多任务访问 | 显式处理错误；MainActor 隔离状态，共享拉取任务并限制单个推送循环 |
| 无云端配置的合法 `data: null` 被识别成失败 | 区分成功可空值、缺失数据与引擎失败，增加三类响应测试 |
| FFI 只返回最外层错误，实际解码原因丢失 | 返回完整原因链，增加非法 action、空指针和 UTF-8 测试 |
| 订阅提醒固定上海时区，非法日期可自动滚入下月 | 使用当前设备时区并验证日期；时区变化后重建提醒，覆盖跨时区与非法日期 |
| 订阅日期是 YYYY-MM-DD，却用时间戳格式化，显示“未设置” | 统一使用已有日期格式化入口 |
| OCR 文件导入未持有系统授予的访问范围 | 识别期间获取并成对释放 security-scoped URL 权限 |
| OCR 自动入库和直接资产写入遗漏同步/列表刷新 | 在相应业务写入完成后调度同步、刷新资产；确认资产后刷新资产列表 |
| 两条 macOS 打包链路的身份、签名配置不同；Debug 命令可链接旧库 | 统一 Xcode 构建和签名，Debug/Release 命令固定匹配 Rust 配置，错误子命令和非法构建模式返回失败 |
| 复核：`CloudKitSyncService` 改为 `@MainActor` 后，CloudKit 操作回调闭包被推断为主线程隔离，却在 CloudKit 操作队列上执行并修改共享结果 | 拉取与保存操作移入 `nonisolated` 辅助函数，回调结果写入加锁容器，操作完成后整体交回主线程；标记已同步改为在主线程顺序执行 |
| 复核：CloudKit 中被硬删除的记录会让每次拉取失败，游标永不前进，订阅补算随之停止 | App 只做软删除，硬删除仅来自控制台或数据区重置：改为跳过该条、保留本地数据并记录 `sync.pull.skip` 日志 |
